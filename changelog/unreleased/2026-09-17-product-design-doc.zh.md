# Web 应用公共文档区新增产品设计文档与界面原型

- **日期：** 2026-09-17
- **类型：** docs
- **范围：** `web`, `docs`

[English](2026-09-17-product-design-doc.md)

`packages/web/public/docs/product-design.html` 是一个自包含单文件页面（无外部依赖，含深色模式），
回答"这个产品是什么、怎么运转、每一屏在做什么"：阅读指引、产品全景、对象模型与执行模型、进程与
存储架构、六条核心时序（一次请求、重连阶梯、压缩、恢复、消息入站、上下文装配）、按模块写的操作
手册、十六屏静态原型、权限矩阵、术语表与附录。

## 细节

- 原型按真实布局、真实导航与真实中文文案重绘，因此它们描述的是已发布的界面而不是设想；其中的凭据、
  会话 id 与数字全部是演示数据。
- 容易被记错的事实都写明出处：插件库是 12 个包（是数据不是代码，由 core 的加载器解析）、内置工具是
  7 个、四种结束状态把细节放在错误码字段上。
- 附录 E 集中记录仓库说明文档与代码不一致之处，并以代码为准，使下一位读者看到的是写下的说明而不是
  一次意外。
- 放在 `public/` 下意味着它随 Web 应用一起发布，下一次 Web 构建后可在
  `/docs/product-design.html` 访问；它没有接入文档站。
