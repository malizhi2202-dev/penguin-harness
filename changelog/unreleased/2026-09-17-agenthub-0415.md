# The AgentHub client moves to 0.4.15

- **Date:** 2026-09-17
- **Type:** fix
- **Scope:** `core`, `cli`

[中文版](2026-09-17-agenthub-0415.zh.md)

`@prismshadow/agenthub` is raised from `^0.4.11` to `^0.4.15`.

## Details

- 0.4.15 keeps every function call of an interleaved parallel tool-call turn, so a gateway that
  opens every call before closing any no longer loses all but the last one, and the next
  request no longer fails on an orphaned `function_call_output`.
- 0.4.12–0.4.14 shape what a tool result looks like on the wire for the OpenAI Chat, Kimi K3,
  GLM, DeepSeek V4 and GPT Responses clients, and replay a tool-calling assistant turn with
  its reasoning field present even when the model produced no chain of thought.
