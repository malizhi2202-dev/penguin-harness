# 侧栏新增代码仓库页：项目下的本地 git 仓库

- **日期：** 2026-09-21
- **类型：** feature
- **范围：** `server`、`web`

[English](2026-09-21-git-page.md)

侧栏导航组里新增「代码仓库」（`/git`）：当前项目各工作区下的本地 git 仓库，连同提交日志、工作区改动与
分支，全部直接读服务端磁盘上的 `.git`。全程不经过任何托管平台——这里看到的就是这些工作区里的会话正在改的
那份检出。

## 细节

- 按工作区发现。候选目录来自该项目会话跑过的工作区，再加上侧栏已登记的工作区与页面上手动挑选的目录；
  每个候选都会解析到所在仓库的顶层，所以同一个仓库里的多个工作区只算一行，不在任何仓库里的目录会被跳过
  而不是报成错误。扫描有上限，超出多少会如实写出来，不静默截断。
- 读取：单个仓库的分支、与上游的领先/落后、状态计数、分支与远程列表；分页的提交日志；单个提交的信息正文、
  逐文件行数与补丁；单个文件相对索引、相对工作区，或某个提交中的差异。未跟踪文件与 `/dev/null` 对比，
  所以新文件在加入索引之前就能看到内容。
- 写入：暂存、取消暂存、提交（可选修补上一次）、切换到已存在的分支，以及抓取/拉取/推送。提交只需要一条
  提交信息——暂存是单独的按钮，所以提交不会顺手带上没被选中的文件——每条命令的 git 输出都按原样展示。
- 所有传给 git 的参数都在服务层校验：版本号先解析成 SHA 再使用（因此 `--output=…` 不会被当成版本号），
  越出仓库的路径会被拒绝，分支名以 `git for-each-ref` 的结果为准；git 以 `GIT_TERMINAL_PROMPT=0` 运行并带
  逐命令超时，任何路由都不会卡在凭据提示上。
- 所有路由沿用既有的项目访问规则（无权限者得到 404 而非 403），挂在 `/api/projects/:projectId/git/` 下。
